# קבצי תוכן

## להשלים מהאתר הישן (Base44)

שלושת הקבצים האלה ריקים בכוונה. צריך להעתיק אליהם את התוכן האמיתי מהאתר הנוכחי, כמו שהוא. לא ממציאים כלום.
כל עוד קובץ ריק, האזור שלו לא מוצג באתר, ולא נוצר עבורו סימון מובנה (schema).

### reviews.json — ביקורות
```json
[
  {"name": "דנה כ.", "lang": "he", "rating": 5, "text": "הטקסט המלא של הביקורת", "date": "2025-06-01", "source": "Google"}
]
```
- `lang`: השפה שבה הביקורת נכתבה (`he` או `en`). כל ביקורת מוצגת בשתי גרסאות האתר, בשפה המקורית שלה.
- `rating`: ‏1 עד 5. השדות `date` ו-`source` לא חובה.
- דירוג ממוצע (AggregateRating) נכנס ל-schema רק אם יש ביקורות.

### tours.json — סיורים
```json
[
  {"slug": "jerusalem-old-city",
   "he": {"name": "...", "duration": "8 שעות", "desc": "...", "price": "..."},
   "en": {"name": "...", "duration": "8 hours", "desc": "...", "price": "..."}}
]
```
- מוצגים בעמוד ‎/israel-private-tours‏. השדות `duration` ו-`price` לא חובה.
- אם חסרה שפה אחת, מוצגת השפה השנייה.

### faq.json — שאלות נפוצות
```json
[
  {"he": {"q": "שאלה", "a": "תשובה"}, "en": {"q": "Question", "a": "Answer"},
   "pages": ["ben-gurion-airport-transfers"]}
]
```
- כל השאלות מוצגות בעמוד ‎/faq‏. עם `pages` השאלה מוצגת גם בעמודי השירות שברשימה.
- עמוד ‎/faq‏ נוצר רק כשיש בקובץ לפחות שאלה אחת.

## קבצים נוספים
- `business.py`: פרטי העסק, הצי וטקסטים של הממשק.
- `services.py`: שמונת עמודי השירות. ה-slug-ים זהים לכתובות באתר הישן, ואסור לשנות אותם.
- `articles.py`: המאמרים.
