# קבצי תוכן

| קובץ | מה יש בו |
|---|---|
| `pages.py` | כל עמודי התוכן: כתובת, שפה, עמוד מקביל בשפה השנייה (`alt`), טקסטים, רכבים מתאימים וקישורים. |
| `services.py` | טקסטים בסיסיים ש-`pages.py` משתמש בהם עבור 8 השירותים הראשונים. |
| `articles.py` | 6 המאמרים, בעברית ובאנגלית. |
| `legacy.py` | המאמר שנשמר מהבלוג הישן, וכל ההפניות (301) מכתובות ישנות. |
| `business.py` | טלפונים, הצי וטקסטים של הממשק. |
| `reviews.json` | 16 הביקורות מהאתר הישן. ביקורת מוצגת בעמודי השפה שיש לה בה טקסט. |
| `tours.json` | 8 הסיורים מהאתר הישן. |
| `faq.json` | השאלות הנפוצות מהאתר הישן. כל שאלה משויכת לעמוד (`page`). שאלה עם `hidden` לא מוצגת, והסיבה כתובה בשדה. |

הטקסטים בקובצי ה-JSON הועתקו מילה במילה מהייצוא של Base44 (16/11/2026).

**הוספת עמוד:** מוסיפים רשומה ב-`pages.py`, מריצים `python3 build.py && python3 tests/check.py`.
**הסרת עמוד:** חשוב להוסיף לו הפניה ב-`legacy.py`, כדי שהכתובת לא תחזיר שגיאה בגוגל.
