# פקודה לייצוא התוכן מ-Base44

מעתיקים את כל מה שבתוך המסגרת ומדביקים בצ'אט של Base44.
אחרי שהוא עונה: מורידים את הקובץ שהוא נתן (או מעתיקים את כל התשובה) ושולחים ל-Claude.

```
אני מעביר את האתר לאחסון אחר, ואני צריך ממך ייצוא מלא של התוכן הקיים.
חשוב מאוד: אל תשנה שום דבר באתר, ואל תמחק או תערוך שום תוכן. רק תייצא.

תעתיק את הטקסט בדיוק כמו שהוא מופיע באתר, מילה במילה, בלי לקצר, בלי לתקן, בלי לתרגם ובלי להוסיף שום דבר שלא כתוב באתר.
אם משהו קיים רק בעברית או רק באנגלית, תשאיר את השפה השנייה ריקה. אל תתרגם בעצמך.

תכין לי קובץ אחד מסוג JSON בשם tour-vip-export.json עם 4 חלקים:

1. "reviews" - כל הביקורות באתר. לכל ביקורת:
   - name: שם הכותב
   - text: הטקסט המלא של הביקורת
   - rating: מספר הכוכבים (1 עד 5), אם יש
   - date: התאריך, אם יש
   - source: המקור (למשל Google), אם מופיע
   - lang: "he" אם הביקורת בעברית, "en" אם באנגלית

2. "tours" - כל הסיורים באתר. לכל סיור, בעברית ובאנגלית:
   - name: שם הסיור
   - desc: התיאור המלא
   - duration: משך הסיור, אם מופיע
   - price: מחיר, אם מופיע

3. "faq" - כל השאלות הנפוצות באתר. לכל שאלה:
   - he: השאלה והתשובה בעברית
   - en: השאלה והתשובה באנגלית
   - pages: באילו עמודים באתר השאלה מופיעה

4. "pages" - רשימה של כל הכתובות (URL) של כל העמודים באתר, כולל עמודי מאמרים, ועמודים באנגלית אם יש להם כתובת נפרדת.

תכלול את כל הפריטים, לא רק דוגמאות.
אם התוכן שמור בטבלאות נתונים (entities), תייצא את כולן. אם הוא כתוב ישירות בתוך העמודים, תעתיק אותו משם.
אם אתה לא יכול ליצור קובץ, תכתוב את כל ה-JSON כאן בתשובה, ואני אעתיק אותו.
```
